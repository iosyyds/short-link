# 短链 · 链接缩短工具

一个纯静态、无需注册的短链接生成网站，托管于 GitHub Pages。

## 特性

- 一键把长链接缩短为易分享的短链
- 支持自定义别名（4–30 位字母或数字）
- 短链二维码，扫码即可访问
- 历史记录保存在本机浏览器，支持单条删除与一键清空
- 液态玻璃质感，自动适配深色模式，移动端友好
- 严格 CSP 安全策略，所有动态内容安全转义

## 技术说明

- 单文件 `index.html`，原生 HTML / CSS / JavaScript，无构建步骤
- 短链生成与跳转由 [v.gd](https://v.gd) 提供，网络异常时自动降级 [da.gd](https://da.gd)
- 二维码通过 jsDelivr 加载 qrcode 库在本地生成
- 历史记录使用 localStorage，不上传任何服务器

## 部署

推送到 GitHub 仓库后，在 Settings → Pages 选择 `main` 分支根目录即可发布。
