# 短链 · 链接缩短工具

一个纯静态、无需注册的短链接生成网站，托管于 GitHub Pages。

## 特性

- 一键把长链接缩短为易分享的短链
- 打开短链直接 302 跳转到原链接，无中转确认页
- 支持自定义别名（4–30 位字母、数字、连字符或下划线）
- 短链二维码，扫码即可访问
- 历史记录保存在本机浏览器，支持单条删除与一键清空
- 液态玻璃质感，自动适配深色模式，移动端友好
- 严格 CSP 安全策略，所有动态内容安全转义

## 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤
- 短链生成与直接跳转由 [da.gd](https://da.gd) 提供，网络异常自动重试，链接无过期时间
- 二维码库本地化，在浏览器本地生成，不依赖外部服务
- 历史记录使用 localStorage，不上传任何服务器

## 部署

推送到 GitHub 仓库后，在 Settings → Pages 选择 `main` 分支根目录即可发布。
